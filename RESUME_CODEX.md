## 8) Commands to run locally
- API:
  .\.venv311\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
- Dashboard:
  .\.venv311\Scripts\python.exe -m streamlit run dashboard/app.py --server.port 8501
- Seed:
  .\.venv311\Scripts\python.exe scripts\seed_collectors.py
  Optional:
  --include-odc  (adds ODC placeholder data)
  --skip-chroma  (skip ChromaDB)
- One-shot:
  .\scripts\run_local.ps1 -StartChroma -Seed

## 9) Known issues / warnings
- Uvicorn --reload triggers restarts due to .venv311 (Plotly file writes).
  - Use no --reload, or ignore .venv311 in watchfiles.
- ChromaDB telemetry warning:
  "capture() takes 1 positional argument but 3 were given"
  - Non-blocking, can ignore for now.
- MEF SSL warnings:
  - Collector retries without verification; data still loads.
- Chroma server port: CHROMA_PORT=8000 same as API port.
  - If you want external Chroma server, move it to another port or change API port.

## 10) Perplexity and Claude

- To generate analyses, run daily_pipeline manually or via scheduler.
